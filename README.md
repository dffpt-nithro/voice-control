# Voice Control

Учебный проект по разработке программы для голосового управления компьютером.  
Предназначен для обычных пользователей ПК, позволяет управлять компьютером с помощью голосовых команд: регулировка громкости, запуск и закрытие приложений, диктовка текста, чтение экрана, поиск в интернете и многое другое. Работает на Windows.

## Возможности
- **Распознавание речи** – русский и английский языки
- **Активация по кодовому слову** – скажите «улитка» (настраивается), и помощник начнёт слушать
- **Глобальная горячая клавиша** – клавиша `ПРОБЕЛ` мгновенно активирует прослушивание, даже если окно свёрнуто
- **Голосовое подтверждение** – помощник отвечает голосом на русском или английском (синтез речи)
- **Управление громкостью** – увеличение/уменьшение, отключение/включение звука, точная установка уровня (0–100%)
- **Запуск и закрытие приложений и веб-сайтов**
  - Блокнот, Калькулятор, Microsoft Word, Microsoft PowerPoint
  - Браузер (по умолчанию Яндекс), Google Chrome, Яндекс Браузер
  - Е‑курсы СФУ, Расписание СФУ
  - **Любое приложение по имени** – помощник сам найдёт и запустит программу, если она есть на рабочем столе или в Program Files
- **Веб-поиск** – по команде «ищи …» открывается Google с результатами или «ищи» и после небольшой паузы диктовать длинный запрос до слова «стоп»
- **Диктовка текста** – скажите «пиши», и программа начнёт вводить ваш голос в активное окно (остановка по команде «стоп»)
- **Чтение экрана** – произносит выделенный текст
- **Переключение языка** – русский / английский кнопкой в окне
- **Отключение голоса помощника (mute)** – кнопка в интерфейсе мгновенно выключает/включает звук
- **Ручной ввод команд** – текстовое поле в окне для набора команды с клавиатуры
- **Сворачивание в системный трей** – при закрытии окна программа продолжает работать в фоне, слушая кодовое слово и пробел
- **Иконка в трее** с меню «Показать» / «Выход»

## Установка

### Из исходников
1. Убедитесь, что у вас установлен Python 3.13.13.
2. Склонируйте репозиторий:

	git clone https://github.com/dffpt-nithro/voice-control
	cd voice-control

3. Установите зависимости:

	pip install -r requirements.txt

4. Убедитесь, что в папке проекта лежит файл интерфейса `form.ui` (поставляется вместе с исходниками).

### Готовый EXE
Скачайте последнюю версию исполняемого файла из [раздела релизов](https://github.com/dffpt-nithro/voice-control/releases). Установка не требуется, просто запустите `VoiceControl.exe`.

### Важное требование для русской озвучки
> **Важно!!!** Русская озвучка работает только если в Windows установлен **русский голосовой пакет**. Без него помощник не сможет произносить русские фразы.  
> **Как установить:**
> 1. Откройте **Параметры** → **Время и язык** → **Язык**.
> 2. Нажмите **Добавить язык**, найдите и выберите **Русский**.
> 3. После установки нажмите на **Русский** → **Параметры** → **Добавить голос**.
>
> После этого русская озвучка станет доступна.

## Использование

### Основной интерфейс
После запуска открывается окно приложения, которое всегда отображается поверх остальных окон (можно свернуть в трей).  
В окне расположены:
- **Кнопка микрофона** (`🎤`) – запускает/останавливает голосовой ввод.
- **Текстовое поле и кнопка «Отправить»** – позволяют ввести команду вручную (например, «открой блокнот»).
- **Переключатели языка** (`RU` / `EN`) – мгновенно меняют язык распознавания и голоса помощника.
- **Кнопка отключения звука** (`🔊`/`🔇`) – включает/выключает голосовые ответы помощника.
- **Статус** - последняя распознанная фраза или результат выполнения.

### Системный трей
При закрытии окна (крестик) программа не завершается, а сворачивается в системный трей (область уведомлений).  
Иконка в трее позволяет:
- **Двойной клик** – показать окно.
- **Правая кнопка мыши** – открыть меню: «Показать», «Выход».

Даже когда окно скрыто, продолжают работать:
- **Кодовое слово** – произнесите «улитка», и помощник активируется.
- **Глобальная клавиша `ПРОБЕЛ`** – работает в любой программе, мгновенно включает прослушивание.

### Голосовые команды
Поддерживаются русский и английский языки (переключение кнопкой в окне).  
Ниже приведены примеры для русского языка.

**Управление громкостью**
- *«громче»*, *«тише»*
- *«включи звук»*, *«выключи звук»*
- *«звук на 50»* (число от 0 до 100)

**Открыть / запустить**
- *«открой блокнот»*, *«запусти калькулятор»*, *«открой ворд»*, *«открой презентацию»*
- *«открой браузер»*, *«открой гугл»*, *«открой яндекс»*
- *«открой е‑курсы»*, *«открой расписание»*
- *«открой steam»*, *«запусти телеграм»* – программа найдёт приложение в системе и откроет

**Закрыть**
- *«закрой блокнот»*, *«закрой калькулятор»*, *«закрой браузер»*, *«закрой ворд»*

**Поиск в интернете**
- *«ищи погода в Москве»* – откроется Google с результатами

**Диктовка (голосовой ввод)**
- Скажите *«пиши»* – помощник начнёт записывать всё, что вы говорите, и вставлять текст в активное окно. Для остановки скажите *«стоп»*.

**Чтение экрана**
- *«читай»* – зачитает выделенный текст.

**Выход из программы**
- *«выход»*, *«выйти»*, *«стоп»*, *«exit»*

## Настройки
Все персональные параметры хранятся в файле `settings.json`, который автоматически создаётся при первом запуске.  
Пример содержимого:
```json
{
  "wake_word": "улитка",
  "language": "ru",
  "mute": false
}
```
- wake_word – кодовое слово для фоновой активации (можно изменить на любое).

- language – язык интерфейса и распознавания: "ru" или "en".

- mute – true, если голосовые ответы отключены.

Настройки language и mute также меняются через кнопки в главном окне и сразу сохраняются.
