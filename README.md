# Voice Control

Учебный проект по разработке программы для голосового управления компьютером.  
Предназначен для обычных пользователей ПК, позволяет открывать и закрывать блокнот в Windows с помощью голосовых команд.

## Возможности
- Распознавание речи (русский язык, английский язык)
- Открытие и закрытие блокнота
- Выход из программы
- Оконный интерфейс для мониторинга

## Установка

### Из исходников
1. Убедитесь, что у вас установлен Python 3.13.13.
2. Склонируйте репозиторий:

    git clone https://github.com/dffpt-nithro/voice-control
    cd voice-control

3. Установите зависимости:

    pip install -r requirements.txt

### Готовый EXE
Скачайте последнюю версию исполняемого файла из [раздела релизов](https://github.com/dffpt-nithro/voice-control/releases). Установка не требуется, просто запустите `VoiceControl.exe`.

## Использование
Запустите приложение:

    python main.py

После запуска появится окно приложения. Нажмите кнопку с микрофоном, чтобы активировать прослушивание микрофона. Произнесите голосовую команду (например, *«открыть блокнот»*, *«выход»*).  
Текущий список поддерживаемых команд уточняется — он будет расширяться в следующих обновлениях. Для теста можно использовать команды:
- *«открой блокнот» / «открыть блокнот» / «запусти блокнот» / «запустить блокнот» / «открой notepad»/ «open notepad»* – открыть блокнот
- *«закрой блокнот» / «закрыть блокнот» / «убери блокнот» / «сверни блокнот» / «закрой notepad» / «close notepad»* - закрыть блокнот
- *«выход» / «выйти» / «закрой программу» / «закрыть программу» / «стоп» / «exit» / «quit» / «останови программу»* – выход из программы

Приложение подтверждает выполнение звуковым сигналом.
