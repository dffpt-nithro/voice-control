# Voice Control

Учебный проект по разработке программы для голосового управления компьютером.  
Предназначен для обычных пользователей ПК, позволяет управлять громкостью, открывать и закрывать приложения и веб-сайты в Windows с помощью голосовых команд.

## Возможности
- **Распознавание речи** – русский и английский языки
- **Управление громкостью** – увеличение/уменьшение, включение/выключение звука, установка точного уровня (0-100%)
- **Открытие и закрытие приложений**:
  - Блокнот
  - Калькулятор
  - Microsoft Word
  - Microsoft PowerPoint
- **Открытие веб-сайтов** и **закрытие браузера**:
  - Браузер (по умолчанию Яндекс)
  - Google Chrome
  - Яндекс Браузер
  - Е-курсы СФУ
  - Расписание СФУ
- **Выход из программы** голосом
- **Глобальная горячая клавиша** `ПРОБЕЛ` – активация прослушивания, даже если окно приложения не в фокусе
- **Оконный интерфейс** с отображением статуса выполнения команд
- Звуковое подтверждение при успешном распознавании

## Установка

### Из исходников
1. Убедитесь, что у вас установлен Python 3.13.13.
2. Склонируйте репозиторий:

 git clone https://github.com/dffpt-nithro/voice-control
 cd voice-control
3. Установите зависимости:

 pip install -r requirements.txt

### Готовый EXE
Скачайте последнюю версию исполняемого файла из [раздела релизов](https://github.com/dffpt-nithro/voice-control/releases). Установка не требуется, просто запустите `VoiceControl.exe`.

## Использование
1. Запустите приложение (через `python main.py` или EXE).
2. В открывшемся окне нажмите кнопку с микрофоном **или** нажмите клавишу `ПРОБЕЛ` в любом месте системы – начнётся прослушивание (работает глобально).
3. Произнесите голосовую команду. Приложение подтвердит распознавание звуковым сигналом и отобразит статус в окне.
4. Через пару секунд можно давать следующую команду.

### Примеры голосовых команд
**Управление громкостью**
- *«громче»*, *«тише»*
- *«включи звук»*, *«выключи звук»*
- *«звук на 50»* (число можно любое от 0 до 100)

**Открыть приложение / сайт**
- *«открой блокнот»*, *«запусти калькулятор»*, *«открой ворд»*, *«запусти презентацию»*
- *«открой браузер»*, *«открой гугл»*, *«открой яндекс»*, *«открой е-курсы»*, *«открой расписание»*

**Закрыть приложение / сайт**
- *«закрой блокнот»*, *«закрой калькулятор»*, *«закрой браузер»*, *«закрой ворд»*

**Выход из программы**
- *«выход»*, *«выйти»*, *«стоп»*, *«exit»*, *«quit»*

Все команды можно произносить на русском или английском, а также использовать разные вариации фраз (например, «запусти блокнот» и «открой notepad» работают одинаково).
